# AW2-Select-Any-Mission-Romhack

### Features
This ROMhack will allow you to select any campaign mission from Versus mode, then select any CO you want to use, you can also choose which side will be human and which side will be AI, as well as which team each CO is on

Please try to mess around with it and try different fun variations


### Install Instructions
Please download aw2_select_any_mission.ips, then use an ips patcher and apply it to a legal Advance Wars 2 ROM
